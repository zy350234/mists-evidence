# 迷雾中的证据

六篇按真实发现过程写成的中文科学推理短篇，面向大学一年级学生及对科学与人文探索感兴趣的读者。
**双击 `index.html` 即可离线游玩**，不需要服务器、不需要联网、不需要登录。

---

## 怎么玩

从书架自由选关，六关相互独立，各自保存进度与成绩。每页只推进一件事；在转折处，根据**当时掌握的证据**选择一个最佳答案。

- **答错**会给出这个选项错在哪里，然后你可以重新作答（本题计 60%）。
- **看提示**会点出思考方向，使用后本题最高计 30%。
- **翻开记录**可以展开当时的研究记录、读数或背景事实。
- **倾向与回望**：某些页会让你先留下一个不计分的判断，几页之后再回看它，看新证据怎样改变了这个判断。可以跳过、可以留"我说不准"，都不扣分。
- **简洁阅读**：顶部开关。打开后记录直接展开、倾向互动自动跳过，科学内容与推理题一个不少。
- **导出**：随时把成绩、每题结果、线索本与留下的倾向导出成纯文本，可复制粘贴到任何地方。

### 成绩怎么算

每题等权：首次独立答对计 100%，纠错后答对计 60%，使用提示后答对计 30%；最终取各题平均分并四舍五入。
阅读速度不计分，翻开记录不扣分。进度只保存在当前浏览器（`localStorage`），清除浏览器数据会清除进度。

## 声音

页面里**没有一个音频文件**。背景配乐、四类答题音效全部由 Web Audio 实时合成：

- 配乐：D 小调 · 62 BPM，和声骨架 `i – i – VI – V`（和声小调，V 级制造张力），八小节一轮。包含 D 踏板低音、和声垫、低沉拨弦、稀疏五声旋律、冷金属钟、心跳低频与极轻风声，经程序生成脉冲响应的卷积混响。
- **强度联动**：每答对一题，配乐的"明度"抬升、"张力"下降；答错则相反（并伴随一次低音下坠）。明度实时改变和声垫的滤波截止、旋律密度与钟声概率；张力改变踏板低音、风声与心跳间隔。阅读器右下角两条细条就是这两个值的实时读数。
- 音效：答对（上行五度）、答错（小二度失谐 + 噪声撞）、翻页（带通噪声扫频）、线索入册（高音钟）、翻开记录、留下倾向。
- 全部为原创合成，不含任何第三方音乐素材。音乐与音效可以分别关闭，音量可调；音频初始化失败不会阻止通关。

## 加一关要改什么

整个游戏由一份数据驱动，不需要碰逻辑。在 `index.html` 的 `CHAPTERS` 数组里追加一个对象即可，
书架会自动多出一张卡片（封面用该关第一页的插图）。

```js
{
  id: "my-chapter",           // 唯一标识，用于存档键
  title: "标题",
  domain: "领域 · 方法",
  difficulty: 3,              // 1–5
  minutes: "20–25",
  ability: "核心能力",
  cover: "horn",              // 插图库里的键名
  pages: [ /* 见下 */ ]
}
```

页面有四种类型：

| type | 作用 | 必需字段 |
| --- | --- | --- |
| `story` | 推进叙述，一个"继续"按钮 | `title`、`text`（段落数组）、`reveal?` |
| `question` | 计分选择题 | `qid`、`text`、`options`、`clue`、`hint` |
| `poll` | 不计分，留下当下判断 | `pid`、`text`、`options` |
| `recall` | 回看之前留下的判断 | `pid`（与 poll 相同）、`text` |

- `question.options` 里在正确答案上写 `ok: true`，其余选项也要写 `why`——**每个错误选项都必须解释错在哪里**，这是这套设计的一半价值。
- `reveal: { label, text }` 是"翻开记录"里藏的内容。
- 每页都要写 `art`，取值是插图库（`ART`）里的键名；缺了会退回兜底插图。

插图全部是代码绘制的 SVG，没有图片文件。要加新插图，在 `ART` 对象里加一个返回 SVG 片段的函数即可（可复用 `grid()`、`stars()`、`L()`、`R()`、`CI()`、`T()` 这些辅助函数）。

## 关于内容

故事依据原始论文、当事人回忆与机构记录写成。**对白不是逐字记录**——凡属事后回忆的转述，正文里都标明了；
**场景串联与比喻经过文学处理**；**插图为示意**，不冒充历史照片或原论文图件，人物、器材与空间关系可能经过简化。
每道题的最佳答案只针对给定证据与当前任务，不代表真实探索只有一条路。

各关结尾的"来源"列出可追查的原始文献。史实细节若与更权威的研究有出入，以权威研究为准。

## 开发工具（可选）

`tools/` 下是无头浏览器验证脚本，平时玩不需要它们：

- `cdp-check.mjs`：加载页面、抓 JS 异常、求值、截图。
- `playthrough.mjs`：用**真实鼠标事件**自动通关全部六关，校验得分是否符合 100/60/30 规则、配乐联动目标是否一致、每关是否留下倾向记录。

用法（需要先以 `--remote-debugging-port=9333` 启动 Edge 或 Chrome）：

```bash
node tools/playthrough.mjs http://127.0.0.1:9333 file:///C:/path/to/index.html ./shots
```
